pyqtkeybind
===========

|pypi|

Overview
--------

Cross platform global keybindings for PyQt.

Versions `0.1.0` onwards support only PyQt6.

For PyQt5 support, please use version `0.0.9`. Qt5 LTS reached end of life as of 
May, 2023.


Installation / Usage
--------------------

To install use pip:

::

    $ pip install pyqtkeybind

Or clone the repo:

::

    $ git clone https://github.com/codito/pyqtkeybind.git
    $ python setup.py install

Example
-------

See https://github.com/codito/pyqtkeybind/blob/master/sample/hotkey.py
